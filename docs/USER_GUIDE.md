# MaestrWave 用户使用指南

> 这份文档是**助手的知识来源**（`backend/agent.py` 会把它整篇读进系统提示）。
> 所以它必须描述**软件实际的样子**：真实的页面名、真实的按钮、真实的限制。
> 写了而软件里没有的东西，会变成助手对用户的一次误导；宁可少写一条，不要多写一条。
> 改了界面就回来改这里。

## 1. 这是什么

MaestrWave = **AI 生成管弦乐素材 + 用身体指挥它**。

不是播放一首固定的曲子，而是十几条声部各自独立播放，你的手势实时改变它们的
音量、速度和平衡。不需要会乐理，也不需要学过指挥 —— 软件里自带从第一课开始的教程。

管弦乐是核心：四个乐器族、十三件乐器（弦乐、木管、铜管、打击乐；「打击乐」指的是
定音鼓与铙钹，不是流行鼓组）。

## 2. 界面结构

左侧导航是**两条并列的路径**，不是父子关系：

- **指挥教学** —— 从零学怎么打拍子。下辖「课程」「考试」。
- **指挥体验** —— 做一首曲子再指挥它。下辖「文件 → 构型 → 生成 → 浏览 → 输出」五步，顺序就是流程。

底部两项不属于任何一条路径：**训练**、**设置**。点左上角的品牌名回首页。

右下角有一颗**可以拖动的悬浮球**，点开是助手对话框（就是你正在用的这个）。

## 3. 指挥教学

### 3.1 课程

七课，分三个单元，必须按顺序学 —— 后一课建立在前一课之上：

- **单元 1 拍子怎么打**：01 站姿与手的位置、02 基本图形拍型（2/3/4 拍）、03 打 1 拍
- **单元 2 两只手分开用**：04 非持棒手的职责、05 从非第一拍起
- **单元 3 把音乐讲出来**：06 力度：拍型的大小、07 渐慢与渐快

侧栏里「课程」下面就列着这七课，可以直接跳。每一课页面的结构固定：

1. **讲解** —— 这一课要练成什么、标准依据、要点、常见错误。
2. **示范** —— 动画画出标准的图形拍型轨迹，光点按拍走。多拍号的课可以切 2/4、3/4、4/4；下面有「示范速度」滑块（60–120 BPM）。
3. **跟练** —— 现场生成一首练习曲，用摄像头跟着打。开头有一小节数拍，数完接第 1 拍。
4. **评分** —— 打完按维度给分，并给出讲评。

左上角有「返回」，回到你进来之前那一页。

### 3.2 考试

用**固定的曲目**打分，摄像头采集。和课程里的跟练分开，是因为可比性：练习曲跟着
本课的拍号速度走，换一课就换一首，分数没法横向比；考试用同一批曲目，分数才有意义。

考前会先自检：环境、摄像头、认不认得到手、帧率。

## 4. 指挥体验（五步）

### 4.1 文件

三块内容：

- **新建项目** —— 填名称、总时长，选**生成方式**。生成方式建项目时就定死，之后不能改：
  - **分轨生成**：每件乐器单独调音乐模型生成一条音轨。音色真实，但各声部只能靠调性和速度对齐。
  - **写谱演奏**：AI 先写出每件乐器的谱子，再由采样器演奏。速度和拍点精确，声部之间真正配合；音色取决于音源。
- **内置曲目** —— 随程序附带的真实交响乐作品，公有领域：贝多芬《第七交响曲》第二乐章选段（46 秒 / 12 个声部）与《埃格蒙特》序曲的胜利尾声（46 秒 / 14 个声部）。第一次点开会把每个声部渲染成独立音轨，要等十几到几十秒；渲完就是一个正常项目，一样能改配器、一样能指挥。**一首只会生成一个项目**，之后再点是打开它。
- **已有项目** —— 你做过的项目，点开继续。

### 4.2 构型

**在生成之前确定乐曲的全局属性与情绪曲线。** 这一页决定的是「这首曲子长什么样」，
而不是某一件乐器怎么演奏。具体能做的：

- 选**模版**，或从零开始。
- 编辑**段落**（每段的名字、时长、情绪强度），拖动边界改时长。
- 看**情绪柱状图** —— 横轴是时间，柱高是那一刻的参与度；高潮段一眼就能找到。
- **增删乐器**，给每件乐器定声部（主旋律/和声/低音/节奏）与出场层级（贯穿/高潮/点缀）。
- 顶上有一个**自然语言输入框**：用一句话描述你想要的，它会改写整个构型。这是**单次改写**，不是多轮对话 —— 每次都以当前的完整构型为输入，所以你在图上拖过、删过的东西不会被旧的对话历史覆盖。

没配语言模型 API key 也能用：模版、段落编辑、拖拽、乐器增删全部照常，只有那个
自然语言输入框用不了。

### 4.3 生成

逐件乐器生成音频。左边选乐器，右边写这件乐器的提示词，生成出来的每一次结果叫
一条 **take**，同一件乐器可以生成多条、挑一条当前使用。生成结果能看波形，写谱演奏
模式下还能看钢琴卷帘。

### 4.4 浏览

把所有声部的波形排在一起，可以单独播一条（solo）或者全部一起播。想改哪条就跳回
「生成」页改。

### 4.5 输出（指挥台）

真正指挥的地方，整屏铺开：

- **两侧到顶的音量条** —— 左边是主旋律、和声，右边是节奏、低音。位置和摄像头画面里的席位分区对得上：手往哪边指，哪边的边条就亮。
- **中间是动作轨迹** —— 摄像头模式下就是你自己的画面，手走过的路留一段渐隐的光迹，确认一个拍点时会有一圈水波纹从拍点位置扩散出去。
- **右上角的拍型小窗** —— 乐曲现在走到第几小节第几拍，画成图形拍型，亮的那个点就是当前拍。注意它显示的是**乐曲的拍**。
- **打完一拍整块屏幕闪一下** —— 这个是**你打的拍**。两者对齐就说明你跟上了。
- **左上角的大字读数** —— 现在的速度（BPM），下面是曲子的基准速度。两个数一样就是正好在拍子上。
- 中间下方的圆形按钮「开始指挥 / 停止」。

## 5. 怎么指挥

**用什么设备打拍子在「设置」页选**（设置 → 指挥 → 指挥方式），不在输出页上。两种方式
解析出来的是同一种「指挥意图」，声部逻辑、力度与速度的算法完全一样，差别只在
手势从哪儿采集：

- **摄像头模式**（默认）—— 不用手机，直接对着电脑摄像头指挥。摄像头需要安全上下文：用 localhost 访问，或以 HTTPS 启动。
- **电脑模式** —— 手机扫码当指挥棒，声音从电脑放出。输出页上会给二维码和房间码；手机可以走局域网（同一个 Wi-Fi，延迟最低，iPhone 需要先装 mkcert 根证书），也可以走公网隧道（任何手机零安装，也不要求同一网络）。

### 5.1 摄像头模式下双手怎么分工

按指挥法的标准分工：

- **打拍手**（默认右手，可在输出页勾选「左手打拍」换成左手）：画图形拍型，控制拍点与速度。**拍型越大，力度越强。**
- **表情手**：抬高是渐强、落下是渐弱；横向位置按乐队席位决定强调哪个声部 —— 偏左强调主旋律，居中强调和声，偏右强调低音。
- 只伸一只手时，这只手同时管两件事。

### 5.2 手势对应什么

- **挥动幅度** → 力度（整体音量与声部对比度）
- **挥动速度** → 曲子的速度。范围是基准速度的 0.7–1.3 倍，而且**变速不变调** —— 拖快拖慢都不会跑调。
- **朝向/横向位置** → 强调哪个声部
- **停下并做收势动作** → 音乐自然衰减收尾

## 6. 设置

分三组：

- **指挥** —— 指挥方式（摄像头 / 电脑）、音画延迟校准（让你打下去的那一拍和听到的那一声对齐；蓝牙耳机通常还有 150~250ms，不校准的话每一拍都会被判成拖拍）。
- **生成** —— 语言模型（自带 API key，只支持 OpenAI 兼容的端点；key 只存在后端，不进浏览器）、作曲器（谁来写谱：大模型 / 外部符号模型 / 规则作曲）、音源（谁来演奏：内置采样 / FluidSynth / 内置合成）、LoKr / LoRA 权重。
- **系统** —— 后端状态与能力，只读。

## 7. 训练

用自己的数据微调生成模型（LoRA / LoKr）。**这一页目前还没接上训练后端，按钮是禁用的**，
表单可以填但跑不起来。

## 8. 常见问题

- **某条声部没有声音** —— 先到「浏览」页看那一条有没有波形。没波形就是还没生成，回「生成」页生成；有波形但听不见，多半是指挥时那个声部的音量被压到很低了。
- **点了「开始指挥」没反应** —— 摄像头模式看是不是权限被拒；电脑模式看手机连上没有（输出页会显示接入了几台手机）。
- **摄像头认不到手** —— 站远一点，让上半身和手都完整进画面。只认到一只手且不是打拍手时，画面上会明说。
- **拍子总被判成不准** —— 先做音画延迟校准（设置 → 指挥）。
- **助手答不上来** —— 它只知道这份指南、应用内的课程数据、以及你当前打开的项目摘要。超出这些的它会直说不知道，不会编。

## 9. 这个软件不做什么

写在这里是为了让助手不要凭想象回答：

- **没有手机振动反馈**，也没有任何触觉反馈。
- **没有单独的「新手模式」开关** —— 教程就是「指挥教学」那七课。
- **没有全局的音量 / 波形 / 反馈强度设置** —— 设置页里只有第 6 节列的那几项。
- **没有 MIDI 键盘或外部控制器输入。**
- **不能中途更换项目的生成方式**（建项目时就定死了）。
